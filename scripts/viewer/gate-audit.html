Reports

Saved analyses land here in Phase 2, once the agent bridge (POST /agent) exists. Nothing is stored yet — the deterministic presets above print into the console instead.
A report is a frozen snapshot of one analysis — the verdicts, the numbers and the written explanation — so you can compare today's behaviour against last week's instead of relying on memory.

Backtest

Reads the live TradingView Strategy Tester — no simulator is written. Lands in Phase 3: configure inputs, run, then equity curve, key metrics and trades.
A backtest replays a strategy over past bars to estimate how it would have performed. Headline numbers to read first: profit factor, max drawdown and win rate. Past results never guarantee future ones.

Optimize

Parameter sweep across input combinations, with equity-vs-baseline overlay and a results matrix. Lands in Phase 4.
A sweep re-runs the backtest once per combination of settings. Treat the winner as a direction, not a result — picking the best of many runs on one window is how overfitting happens. Re-check on a date range you did not tune on.
